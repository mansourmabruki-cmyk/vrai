Lorsque les coordonnées saisies/capturées se trouvent à moins du rayon indiqué d'une zone sensible répertoriée par l'IPIS (présence de groupe armé / interférence), une alerte s'affiche automatiquement dans la fiche d'exploration. 859 zones sensibles intégrées (données réelles IPIS, hors-ligne).

📲 Versions & mises à jour des APK

Publiez un petit fichier JSON indiquant la dernière version de chaque APK et son lien de téléchargement. L'application compare automatiquement avec la version installée et signale les mises à jour. Laissez vide pour désactiver. Format et exemple dans le Guide.

☁️ Espace cloud partagé (APK ↔ logiciel)

Quand une connexion est disponible, l'APK et le logiciel partagent les mêmes données via cet espace. Laissez vide pour un fonctionnement 100 % local. Voir le Guide pour créer un espace gratuit.
